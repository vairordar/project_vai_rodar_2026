# Vai Rodar

Repositorio principal del MVP Vai Rodar.

## Carpetas oficiales

- `frontend-app/`: app principal del usuario.
- `frontend-workshop-register/`: registro publico de talleres/oficinas.
- `frontend-backoffice-workshop/`: backoffice futuro para talleres.
- `frontend-backoffice-admin/`: backoffice futuro para administracion Vai Rodar.
- `backend/`: Apps Script actual y backend Supabase futuro.
- `docs/`: documentacion del proyecto y deploys.
- `prototypes/`: prototipos e historico, no produccion.
- `archive/`: material legado.
- `exports/`: exports antiguos o artefactos, no fuente oficial.
